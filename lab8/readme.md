# LAB 8 : Add an APB to TinySoC

The Advanced Peripheral Bus (APB) is a simplified, low-power bus used in system-on-chip (SoC) designs to connect peripheral devices that do not require the high-performance capabilities of the Advanced High-performance Bus (AHB). While the AHB Lite bus is efficient for high-speed data transfer between cores, memory, and high-bandwidth peripherals, it is often overkill for lower-speed devices like timers, UARTs, and GPIOs. Placing everything on the AHB bus would increase complexity and power consumption, as AHB operates with a more sophisticated protocol and requires more resources. By using APB for these slower peripherals, the system achieves better efficiency and simplicity. The two buses communicate via a bridge, which acts as an interface that translates the higher-performance AHB signals to the more straightforward APB protocol, ensuring seamless data transfer while maintaining performance optimization for different components.

In this lab experiment, we will add an APB with a simple slave that has only one I/O register (`apb_slave.v`). The APB is connected to the AHB using a bridge (`apb2ahbl.v`). The APB fabric implementation is in the file (`apb.v`).
